# FilterCopy ユーザーガイド

Windows用の「フィルタして貼り付け」ユーティリティです。エクスプローラーでコピーしたファイルを条件で絞り込み、フォルダ構造を保ってコピーできます。

## 導入

1. GitHubのReleasesからWindows x64用の配布ZIPをダウンロードします。
2. 保存しておきたい場所へZIPを展開します。
3. `FilterCopy.exe`を起動できます。

`self-contained`版は.NETを同梱しているため、追加インストールは不要です。`framework-dependent`版には.NET 10 Desktop Runtimeが必要です。未署名のビルドのため、Windowsの保護機能が確認画面を表示する場合があります。

### 右クリックとショートカットキーの登録

展開したフォルダで、次を実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

管理者権限は不要です。登録スクリプトは隣の実行ファイルを登録するだけで、ビルドやダウンロードは行いません。登録後は展開先を移動しないでください。

登録すると、右クリックの「フィルタして貼り付け」と、常駐中の**Ctrl+Alt+V**を使えます。Windows 11の右クリックでは「その他のオプション」内に表示されます。ログイン時の自動起動も登録します。常駐・自動起動が不要な場合は`-NoStartup`を付けてください。

通知領域のFilterCopyアイコンから、画面の起動・バージョン情報の確認・常駐の終了ができます。

## コピーする

1. エクスプローラーでコピー元のファイルやフォルダを選び、**Ctrl+C**。
2. コピー先へ移動し、右クリックの「フィルタして貼り付け」、または**Ctrl+Alt+V**で起動します。
3. 「対象に含める」にコピーしたいファイルの条件を入力します。
4. 不要なファイルがある場合は「対象から除外する」に条件を入力します。
5. ツリーと件数を確認して「コピー」を押します。

通常起動した場合や、エクスプローラーのタブなどでコピー先を判別できない場合は、フォルダ選択画面が表示されます。

## 含める条件と除外する条件

まず「対象に含める」で選び、その結果から「対象から除外する」に一致したファイルを取り除きます。

- **含める欄が空**：すべてのファイルを候補にします。
- **除外欄が空**：除外しません。
- **両方とも空**：すべてのファイルが対象です。
- **除外条件だけ入力**：すべてのファイルから不要なものを取り除けます。

検索方法・大文字小文字の区別・相対パスの設定は、**両方の欄に共通**で適用されます。

| 検索方法 | 含める条件 | 除外条件 | 結果 |
| --- | --- | --- | --- |
| 通常 | `.dll` | `Test` | 名前に`.dll`を含み、`Test`を含まないもの |
| ワイルドカード | `*.dll` | `*Tests*` | DLLのうち、名前に`Tests`を含まないもの |
| ワイルドカード | 空欄 | `*.pdb` | PDB以外のすべてのファイル |
| 正規表現 | `\.(png|jpg)$` | `^temp` | PNG・JPGのうち、名前が`temp`で始まらないもの |

### 検索方法

- **通常**：入力した文字を含むものを探します（部分一致）。
- **ワイルドカード**：名前全体と照合します。`*`は0文字以上の任意の文字列、`?`は任意の1文字です。例：`*.dll`、`image-??.png`。
- **正規表現**：正規表現で検索します。例：`\.dll$`。`*.dll`をそのまま入力する場合はワイルドカードを選んでください。

「大文字小文字を区別」がオフなら、`A.dll`と`a.dll`を同様に扱います。初期状態ではファイル名を検索します。「相対パスを検索」をオンにすると、選んだフォルダからの階層も検索できます。相対パスの区切りは`\`で、ワイルドカードの`*`は区切り文字にも一致します。

不正な正規表現や処理に時間がかかりすぎる条件はエラー表示になります。どちらの欄に問題があるか表示され、条件を修正するまでコピーできません。

### 履歴

各入力欄のドロップダウンから履歴を選べます。**含める条件・除外条件・検索オプションを一緒に復元**します。除外条件のない以前の履歴も使えます。

コピー時、または画面を閉じる際に最後に検索に成功した条件を保存します。履歴は最大30件で、`%LOCALAPPDATA%\FilterCopy\history.json`に保存されます。

## ツリーと件数

ツリーには最終的なコピー対象のファイルと、その親フォルダだけを表示します。初期表示時・条件更新時には全階層を展開します。手動で折りたたむこともできます。

`対象: 3 / 128 ファイル`は「除外後のコピー対象が3件、コピー元の全ファイルが128件」という意味です。候補が0件の場合はコピーできません。走査できない項目があれば「走査の詳細」で確認できます。

## コピー時の動作と制約

- 選んだフォルダ自体からの階層を保持します。単独で選んだファイルはコピー先直下へ配置します。
- 空フォルダとリンク／ジャンクションはコピーしません。リンクを含むコピー先も対象外です。
- 上書き確認・進捗・キャンセルにはWindowsのコピー画面を使います。中断・失敗時にはコピー済みファイルや作成済みフォルダが残る場合があります。
- コピー元は変更しません。同じファイルへのコピー、コピー元フォルダの内部へのコピー、コピー先で衝突する複数の項目は拒否します。
- 通常のファイルやフォルダが対象です。ZIP内の項目や仮想フォルダは対象外です。

Windowsのライト／ダーク設定に自動で追従します。バージョンとMITライセンス全文は、画面上部または通知領域の「バージョン情報」から確認できます。

## 更新・登録解除

更新時は、通知領域から常駐中のFilterCopyを終了してからファイルを入れ替えます。保存先を変更した場合は、新しい場所で登録スクリプトを再実行してください。

登録を解除するには、FilterCopyを終了した後、展開先で実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1
```

右クリックと自動起動の登録を解除します。実行ファイルと履歴は残します。不要になった場合は、展開したフォルダと履歴をそれぞれ削除できます。
